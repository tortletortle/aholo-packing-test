# 箱子模型与填充物（空隙风险）验证

时间：2026-10-29

## 规则（用户设计）

- 风险由**箱内空格数**决定：空得越多，运输中越容易晃动破损。
- 风险在**封箱的瞬间算出**，之后布局锁定，只保留这个数。
- 封箱后可花钱买不同等级的填充物，降低这个风险。
- 填充物按空格数计价；箱子装满没有空隙时不需要填充。

公式（`src/config/economy.ts`，数值是占位）：

```
空隙率 = 空格 / 总格
基础风险 = min(0.6, 空隙率 × 0.6)
当前风险 = 基础风险 × (1 − 填充物减免)
```

| 填充物 | 每空格价格 | 减免 |
|---|---|---|
| 不加 | 0 | 0% |
| 稻草 | 0.5 | 50% |
| 羊毛 | 1 | 80% |
| 魔法泡沫 | 2 | 100% |

总价 = 空格数 × 单价，向上取整。

## 流程变化

接单 → 选箱 → 装箱 → **封箱（检查空隙）→ 选填充物 → 寄出** → 结算。
寄出时才掷一次破损（风险为 0 则不掷）。破损赔偿 20 金币，从利润中扣。
封箱后不能再改布局或换箱。

## 浏览器实测

| 场景 | 结果 |
|---|---|
| 大箱（4×4×2）装完：空格 23/32，空隙率 72%，基础风险 43% | 与公式一致 |
| 稻草 12 金币 → 22%；羊毛 23 金币 → 9%；泡沫 46 金币 → 0% | 与公式一致 |
| 大箱 + 泡沫：货物完好，利润 −33（50 → 17） | 结算与扣费正确 |
| 小箱（2×3×2）装完：空格 3/12，空隙率 25%，基础风险 15% | 与公式一致 |
| 小箱 + 稻草（2 金币，8%）：完好送达，利润 +20（50 → 70） | 通过 |
| 控制台错误 | 无 |
| 自动测试 | 21/21 通过，构建通过 |

测试覆盖：封箱只算一次且之后布局锁定；空隙大风险高；填充物越好越贵、风险越低、泡沫为 0；破损扣赔偿；结算只发生一次。

## 箱子模型

- 程序生成的木箱（`src/view/crate.ts`）：横向木板、四根角柱、铁箍、木纹贴图（运行时用画布生成，无额外文件）。
- 按任意格数尺寸生成，小箱、大箱不用拉伸。
- 装箱时靠近镜头的一面做成半透明，能看到里面；箱子下面加了桌面。
- 寄出后盖上箱盖。

## 已知问题

- 填充物的团块有些悬在半空，不像沉在箱底。
- 箱盖表面木纹被拉长，有点糊。
- 全部数值为占位，待试玩平衡。大箱 + 泡沫会亏，小箱 + 稻草会赚，这个方向是对的，但差距是否合适要试玩。
- 第二单、第三单、物流公司、保护包装还没做。
